# 🚀 PONZI TOKEN Landing Page

Одностраничный лендинг для крипто-токена в хакерском стиле с **РЕАЛЬНОЙ API интеграцией**.

**✅ 100% ЖИВЫЕ ДАННЫЕ - НИКАКИХ ДЕМО/МОКОВЫХ ДАННЫХ!**

## 🎯 Особенности

- **👻 Phantom Wallet интеграция**: Web3 аутентификация через Phantom Wallet
- **🔐 Реферальная система**: Код генерируется из адреса кошелька как логин
- **📊 Персональная статистика**: Отслеживание приглашений и доходов
- **Хакерский дизайн**: CRT-эффекты, глитч-анимации, терминальный стиль
- **ТОЛЬКО реальные данные**: Множественная API интеграция с 5 источниками
- **Интерактивный калькулятор**: Расчёт прибыли от пирамидальной схемы
- **Живые обновления**: Автоматическое обновление данных каждые 30 секунд
- **Отказоустойчивость**: Автоматическое переключение между API при сбоях
- **Адаптивность**: Полная поддержка мобильных устройств

## 🌐 API Источник

Проект получает данные через SolanaTracker. Ключ хранится на сервере Vercel и не публикуется в браузере или GitHub.

### 🥇 Основные источники данных:
1. **[Solana Tracker](https://data.solanatracker.io)** - Комплексные данные токенов Solana
2. **[DexScreener](https://api.dexscreener.com)** - DEX данные и пары (улучшенный парсинг)
3. **[Solscan](https://api.solscan.io)** - Лучшие данные для Solana токенов (holders, volume за всё время)
4. **[Jupiter](https://lite-api.jup.ag)** - Price API v2 для точных цен
5. **[CoinGecko](https://api.coingecko.com)** - Для популярных токенов

### 📊 Получаемые живые данные:
- **Реальная цена** в USD (обновляется каждые 30 сек)
- **Market Cap** из реальных торгов (FDV если доступно)
- **Total Volume** за всё время существования токена (не только 24h!)
- **Количество холдеров** реальное (из блокчейна через Solscan)
- **Ликвидность пулов** в реальном времени
- **Изменение цены за 24h** в процентах
- **Название и символ токена** автоматически

## 🔧 Быстрый запуск

### 1. Клонируйте проект
```bash
git clone [your-repo-url]
cd ponzi-token-landing
```

### 2. Установите адрес токена
Откройте `script.js` и замените:
```javascript
const TOKEN_ADDRESS = 'YOUR_SOLANA_TOKEN_ADDRESS_HERE';
```

### 3. Запустите локальный сервер
```bash
# Python
python -m http.server 8000

# Node.js  
npx serve .

# PHP
php -S localhost:8000
```

### 4. Откройте в браузере
```
http://localhost:8000
```

## 📞 Поддержка и отладка

### Проверка статуса API
Откройте консоль браузера (F12) и найдите:
```
✅ REAL token data loaded successfully: {data}
📡 Data Source: SolanaTracker
```

### Типичные проблемы:
1. **"No pool data found"** - токен не торгуется на DEX
2. **"All API sources failed"** - проблемы с интернетом
3. **"Token not found"** - неверный адрес токена

### Диагностика:
```javascript
// В консоли браузера:
const api = new TokenAPI('YOUR_TOKEN_ADDRESS');
```

## 🎮 Как использовать

### 👻 Phantom Wallet (Web3 интеграция)
1. **Подключение**: Нажмите "[CONNECT PHANTOM WALLET]"
   - Установите Phantom Browser Extension если нет
   - Подтвердите подключение в Phantom
2. **Реферальный код**: Автоматически генерируется из адреса кошелька
   - Формат: `8 цифр` (хэш из адреса кошелька)
   - Используется как уникальный логин/идентификатор
3. **Статистика**: Просматривайте свои приглашения и доходы
4. **Ввод кодов**: Вводите коды друзей для связи аккаунтов
5. **Отключение**: Кнопка "[DISCONNECT WALLET]" для выхода

### 💰 Калькулятор прибыли
1. Введите количество токенов
2. Укажите количество прямых рефералов
3. Укажите количество косвенных рефералов
4. Получите прогноз прибыли

### 📋 Копирование данных
- **Адрес контракта**: Кнопка "Copy CA"
- **Ваш реферальный код**: Кнопка копирования рядом с кодом

### 🚀 Покупка токена  
- Кнопка "Купить токен" переведёт на pump.fun
